# 软件分层与算法说明

工程按职责划分为 `Algorithm`、`Bsp`、`Device`、`Topic` 和 `App`。板级 DTS 只描述 HPM5361 的控制器、时钟和引脚复用；IMU 寄存器配置、协议解析和算法均由普通 C/C++ 模块显式完成，不使用 Zephyr sensor/remote 的设备绑定驱动。

## 模块职责

- `Algorithm/buffer`：固定容量环形缓冲和双缓冲，不分配动态内存。UART 字节流进入环形缓冲，IMU 原始采样先写入双缓冲，SPI 读取失败时不发布该缓冲区。
- `Algorithm/pid`：可配置 PID，支持微分对测量值（微分先行）或误差求导、死区、积分限幅、输出限幅、积分分离、变速积分、前馈和微分一阶低通。
- `Algorithm/kalman`：通用标量卡尔曼滤波，以及带陀螺零偏估计的角度卡尔曼滤波。
- `Algorithm/quaternion`：四元数归一化、角速度积分、欧拉角互转；姿态更新生成四元数时调用正弦查表。
- `Algorithm/attitude`：组合加速度计与陀螺数据，卡尔曼估计横滚/俯仰，并通过查表正余弦生成四元数姿态。
- `Algorithm/trigonometry`：256 点正弦查表与线性插值，供 IMU 姿态解算调用。
- `Bsp/bsp_uart`：通用 UART 初始化、接收 IRQ 分发、有限长度 DMA 发送队列，以及异步 DMA `printf`。UART 设备和帧格式由板级装配代码传入；队列满、DMA 启动失败或发送超时均丢弃该次输出。
- `Bsp/bsp_spi`：与具体设备无关的 SPI 字节收发；调用方传入控制器、片选 GPIO、频率和 SPI 模式，BSP 不包含任何传感器寄存器协议。
- `Bsp/bsp_gpio`：GPIO 输入中断的注册和使能。
- `Bsp/bsp_fdcan`：CAN 总线配置、发送和接收回调。
- `Device/motor/dji`：`DjiMotorBus` 只处理 CAN 接收队列、按 ID 分发和组帧；每个 `C610Motor/C620Motor` 对象独立保存反馈、目标和控制器。
- `Device/remote/dt7`：只处理 DT7 字节流缓存、帧校验和协议解包，通过通用 `RemoteDevice` 回调输出原始遥控器样本，不依赖 Topic。
- `Device/imu/icm42688p_hxy`：使用 `icm42688p_hxy_reg.h` 完成初始化、寄存器读写和量程换算，通过通用 `ImuDevice` 回调输出样本，不包含姿态算法，也不依赖 Topic。
- `Module/input`：通过双缓冲接收遥控器设备样本，完成通道死区、归一化和功能映射，再发布 Remote Topic。
- `Module/ins`：通过双缓冲接收 IMU 样本，在独立线程执行卡尔曼和四元数姿态解算，再发布 IMU Topic。
- `App/app_chassic`：读取遥控器和 IMU Topic，计算四轮目标速度，并通过每个电机对象的速度环产生电流命令；应用层不解析 CAN 帧，也不直接运行电机 PID。
- `Topic`：按数据域分别定义 `remote_topic` 和 `imu_topic`，只承载模块之间共享的数据结构和 zbus channel。

## 中断与数据流

UART3 的 DBUS 接收使用 UART IRQ；`printf` 仅把格式化结果放入有界队列，由独立线程调用 UART 异步 DMA 发送。SPI 使用 HPM Zephyr glue 的中断传输模式，ICM42688 的数据就绪中断只唤醒 Device 采样线程；样本随后进入 INS 双缓冲并唤醒解算线程。CAN 收发由 HPM CAN 驱动的中断路径完成；CAN 发送队列和发送线程封装在 `DjiMotorBus` 内，底盘控制由 1 ms 定时器信号量唤醒，不主动轮询外设状态。

数据路径如下：

```text
SPI/GPIO BSP -> icm42688phxy Device -> ImuSample 双缓冲 -> INS -> IMU Topic
UART BSP     -> DT7 Device          -> RemoteSample 双缓冲 -> Input -> Remote Topic
CAN BSP      -> DjiMotorBus 队列    -> C610/C620 Device 控制器 -> App chassis
```

发生环形缓冲溢出时，DT7 当前未完成的字节流作废并重新同步；IMU 的 SPI 事务失败时丢弃本次采样；CAN 发送失败或控制帧过期时直接丢弃，不重试旧数据。

## DJI 电机控制层级

`DjiMotorControlMode::Current` 直接向电调提交电流目标，实际电流闭环由 C610/C620 电调内部完成。`Speed` 模式使用速度 PID 根据输出轴速度反馈生成电流目标。`Angle` 模式为串级控制：角度 PID 先生成目标速度，再由速度 PID 生成电流目标。角度和速度均按减速比换算到减速箱输出轴，CAN 报文仍保持 DJI 手册规定的转子编码器、转子转速和转矩电流格式。

CAN 反馈先复制到 `DjiMotorCanFeedback` 线格式结构体，再转换为 `DjiMotorFeedback` 业务结构体。C620 的第 7 字节作为温度，第 8 字节作为错误码；C610 手册规定第 7 字节为空，因此其温度字段不使用。

## HXY ICM42688P

工程使用随项目保存的华轩阳 HXY 版本手册，而不是 TDK 原版 ICM-42688-P 寄存器表。该器件的 `WHO_AM_I` 位于 `0x01` 且返回 `0x6A`，加速度和陀螺连续数据位于 `0x0C` 至 `0x17`，温度位于 `0x22/0x23`，电源控制位于 `0x7D`。SPI 命令的 bit0 是读写位、bit1 至 bit7 是地址，所以 BSP 使用 `(address << 1) | read` 生成命令。手册时序要求时钟空闲为高、下降沿更新、上升沿采样，SPI2 因此配置为 Mode 3。

初始化完成后驱动读取 `DATA_STAT(0x0B)`，若 `GYR_CONF_ERR` 或 `ACC_CONF_ERR` 置位则返回错误。原始加速度、陀螺和温度先进入 Device 内的 `Icm42688pRawFrame` 双缓冲，完整读取成功后才交给 INS；INS 完成解算后才发布 Topic。

## 姿态和调参说明

`PIDConfig::derivative_mode` 设为 `PIDDerivativeMode::Measurement` 时为微分先行，可避免目标突变造成微分冲击；设为 `Error` 时对误差求导。`integral_separation_threshold` 为 0 表示关闭积分分离；`variable_integral_start/end` 描述积分系数从全量线性下降到 0 的误差区间。

当前 IMU 板级输入没有磁力计，横滚和俯仰由加速度计校正，偏航角只能由 Z 轴陀螺积分，因此长时间运行会有航向漂移。需要绝对航向时，应增加磁力计或外部航向观测，再扩展姿态融合器。
